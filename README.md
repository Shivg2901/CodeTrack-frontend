# CodeTrack

CodeTrack is a modern tool to track and analyze your code metrics.  
Built and maintained by Shivansh Gupta.

## Features

- Analyze code metrics for your projects
- Visualize trends and statistics
- User-friendly dashboard

## Getting Started

### Prerequisites

- Node.js (v16 or above)
- npm or yarn

### Installation

```bash
git clone https://github.com/yourusername/codetrack.git
cd codetrack
npm install
```

### Running the App

```bash
npm start
```

The app will be available at [http://localhost:3000](http://localhost:3000).

### Building for Production

```bash
npm run build
```
